# DEEP-STYLE

A fashion e-commerce landing page for a made-up clothing brand called Deep°Style. Built to practice a colorful, editorial grid layout using CSS Grid, not a real store.

## About

The idea was to design something that feels like a trendy streetwear brand's homepage — a bold headline, a scattered photo grid of models on different colored backgrounds, a pull quote, and a small blog teaser at the bottom. I leaned into color and asymmetry rather than a plain, boxy layout.

## Built with

- HTML
- CSS (CSS Grid for the layout)

No frameworks, just plain HTML and CSS.

## Features

- Nav bar with New Arrivals, Shop, Beauty, Sale, and Journal links
- Bold two-line hero headline with a "Summer Collection" tagline
- Asymmetric photo grid built with CSS Grid, each image on its own colored background
- Rotating "Explore More Collection" circular badge
- Pull quote section styled like an editorial magazine spread
- "Scroll down" call-to-action and a small blog/journal teaser at the bottom
- Decorative flower and icon accents scattered through the layout

## Running it locally

```bash
git clone https://github.com/shivamsingh-net/DEEP-STYLE.git
cd DEEP-STYLE
```

Just open `index.html` in your browser after that. Nothing else needed.

## What I was practicing

- Using CSS Grid to build an asymmetric, magazine-style photo layout
- Working with a bold, colorful palette instead of a minimal/neutral one
- Placing decorative elements (icons, rotating badge) without cluttering the layout
- Structuring a fashion/e-commerce homepage with a hero, grid, quote, and footer teaser
